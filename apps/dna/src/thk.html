Thicknesses / THK

The line thickness scale: strokes, dividers, underlines, frames. Seven consecutive values from 1 to 7 px.

Scale

XXS 1 px
SXS 2 px
SZS 3 px
SZM 4 px
SZL 5 px
SXL 6 px
XXL 7 px

Usage

  • Fine accents and dividers — XXS/SXS; control strokes — SZS/SZM; large frames and outlines — SZL+;+;
  • Stroke thickness changes with state: an input focus thickens the frame by one step;;
The only scale without live variables: the values exist only on the canvas vitrine. Before use in Figma they must be digitized: THK/XXS…THK/XXL = 1…7.
