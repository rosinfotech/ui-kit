DNA — the design system core

The UI-Kit foundations: the spatial color model, functional tokens, scales and naming rules. DNA is not the kit implementation but its specification — the contract by which the design system is built and evolved in Figma.

Sections

Semantics / SEM

How everything is named: the registry of three-letter codes, name grammars for tokens and components, step scales.

Absolute palette / CLR

The color raw stock: 11 families × a 40-step scale, plus the special WHT and BLC — 442 tokens with values.

Functional palette / FCL

263 variables: layers, emphases, states, roles. The full table resolved into absolute tokens.

Spacing / SPC

The distance scale 4–64 px: gaps, padding, control heights.

Radiuses / RAD

Radii 4–40 px; the component default is SZS = 12 px.

Thicknesses / THK

Lines and strokes 1–7 px — the only scale without variables.

Typography / TXT

A matrix of 84 styles: Roboto Flex, 6 weights × roman/italic × 7 sizes, with live samples and metrics.

Functional typography / FTY

Ten text roles in Figma order: HD1–HD3, PAR, PRP/PRA/PRN, QTE, QTE_AUT, FTN.

Elevation gradients / GRD

«The top light for elevated components: 8 ABV gradients for PRM and ACC.

The HTML here is only a documentation carrier, not a kit implementation. Every section fixes a foundation: what each code means, how names are assembled, which values are allowed. This base is the contract for the design system in Figma: variables, styles and components are created by it and verified against it. The pages themselves are typeset with FTY roles: headings use HD1/HD2/HD3, body text PAR, captions FTN..
