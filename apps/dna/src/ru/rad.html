Скругления / RAD

Шкала радиусов углов. Каждое значение привязано к собственной переменной (ID 18:3866…18:3872 по шагам XXS…XXL).

Шкала

XXS 4 px · 0.25 rem
SXS 8 px · 0.5 rem
SZS 12 px · 0.75 rem
SZM 16 px · 1 rem
SZL 24 px · 1.5 rem
SXL 32 px · 2 rem
XXL 40 px · 2.5 rem

Применение

  • Скругление компонентов по умолчанию — RAD/SZS = 12 px (переменная 18:3868, она же у рамок витрин);
  • С увеличением размера компонента радиус растёт по шкале: SZS → SZM → SZL;
  • Скругления больше SZL — для крупных поверхностей:
    • карточки;
    • модальные окна;
    • баннеры;
Имена radius-переменных не экспортируются доступными каналами чтения — известны только ID привязок. При сборке библиотеки в Figma имена задаются по шагам шкалы: RAD/XXS…RAD/XXL.
