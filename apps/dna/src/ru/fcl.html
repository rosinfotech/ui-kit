Функциональная цветовая палитра / FCL

Единственный источник цвета для компонентов: 263 переменные, собираемые из слоёв, акцентов, состояний и ролей. Значения ссылаются на токены абсолютной палитры. Ниже — полная таблица всех 90 сочетаний × 3 роли.

Грамматика

<слой>/<акцент>/<состояние>/<роль>
ABV/DFT/RGL/BGR  →  GRY/200 = #DBDBDB
  • Слой — где элемент компонента в пространстве (полный реестр — в Семантике):
    • ABV — приподнят над поверхностью;
    • SFC — несущая поверхность;
    • BLW — утоплен, «в яме»;
  • Смысловые сегменты имени:
    • акцент — смысловая роль компонента;
    • состояние — интерактив;
    • роль — что красим:
      • контент FGR — текст, иконка, глиф;
      • рамка BRD — обводка, граница;
      • BGR — фоновый цвет для переднего плана: то, на чём лежит FGR;
  • У переключаемых компонентов (CHB, TOG, RDB) вместо PRS используется CHD, у полей ввода INP — состояния с суффиксом _FLD;
  • Роли в каждой карточке показаны цветными пластинами с метками ролей;
Пространственность дополняется объёмом: для приподнятых компонентов — градиент света ABV/…/GRD, для глубины — тени <слой>/…/SHD (у ABV тень вниз, у BLW — внутрь ямы).
Порядок ролей в карточках отражает наслоение слоёв внутри одного элемента:
  • для ABV и SFC:
    • FGR — слой переднего плана: текст, графика;
    • BGR — фон для переднего плана;
    • BRD — слой, обрамляющий фоновый;
  • для BLW порядок инвертирован — движемся вглубь:
    • BRD — обрамляющий слой встречает первым;
    • FGR — слой переднего плана;
    • BGR — поверхностный слой, дно;

Как применять

  • Кнопка (не нажата, обычная):
    • фон — ABV/DFT/RGL/BGR;
    • текст — ABV/DFT/RGL/FGR;
    • рамка — ABV/DFT/RGL/BRD;
  • Поле ввода:
    • дно «ямы» — BLW/DFT/***/BGR;
    • введённый текст — BLW/DFT/***/FGR;
  • Карточка — сама поверхность: SFC/DFT/RGL/BGR + тень SFC/DFT/RGL/SHD;
